# Standard (Classic) capture slots

What the companion does for every picture slot a Standard (Classic) harness lab can contain, and what is left. Written from what was read on a real Standard agent on 2026-11-26 (read only, window 1440 by 900) and from Microsoft Learn. Companion 1.8.3 (the recipes themselves are unchanged from 1.8.2). US English, plain text.

**What 1.8.3 changed for these slots.** The Create an agent picture (the Agents list with **More create options** open) and the practice agent creation both find **More create options** by its exact name only and wait up to 60 seconds for it, because a real Agents list draws its controls 15 to 30 seconds after navigation (a fuzzy match used to click the lower left **More options** button instead). The picture is taken only when the menu that opened lists **Agent, Standard**; a different dialog that opened (the account flyout) is closed with Escape and named, and no picture is taken. A Standard practice agent's name now ends with a four-character code from the lab (`Classic shots - <title> <code>`), so two labs never share a name. See [Creating the practice agent reliably](lab-builder.md#creating-the-practice-agent-reliably-companion-183).

A Standard lab takes every Copilot Studio picture in the Standard (Classic) harness, whatever the harness tag of the feature says (a feature tagged `both` is taken in the lab's own harness). The slots here are the 80 slots in `tools/screenshot-capture/feature-shots.json` whose harness tag is `standard` or `both`. The portal list of the same slots is `portal/lib/capture/slots.js`; the recipes are in `tools/screenshot-capture/scratch-recipes.mjs`, `scratch.mjs`, `families.mjs`, and `recipes-builtin.mjs`.

## The three categories

- **a. A real Standard recipe.** Every control name in it was read on the real Standard page. The recipe only opens, shows, or edits the practice agent, and never publishes.
- **b. No recipe can be written from what is known.** The slot needs a dialog, page, form, menu item, setting, or write whose content or name was never read on a Standard agent, or it needs something a person owns (a connection, credentials, files, an admin account, another product, a built topic or flow, Copilot Credits). It ends as Needs you with an exact plain reason, and is never guessed. The read-only reads that would turn it into a recipe are the numbered groups E1 to E11 below, for the coordinator to run on a real tenant with the owner present.
- **c. The slot describes something that is not part of the Standard harness.** It is a catalog harness-tag error, reported for the owner and not captured in a Standard lab.

Result: category a 7 slots (counting the Home picture mc-harness-choice-home.png, which is only opened by address so far), category b 72 slots, category c 1 slot. Of the b slots, 14 are slots the companion would otherwise try on its own, and they now end as Needs you with their own reason (the list is `CLASSIC_UNSEEN_SLOTS` in `tools/screenshot-capture/scratch-recipes.mjs`); the rest were already left to a person.

## What a Standard picture of "Create an agent" is

Both pictures of the feature are taken only from what was verified on a real tenant: the Agents list, its button More create options, the option Agent, Standard, the column Agent harness, and the Standard Overview tab.

1. `create-agent-describe.png` (section agents, kind ui-location). Caption: "Where a Standard agent is created". The Agents page with the More create options menu open and Agent, Standard listed. Recipe `cs.agents.create-options`: open the Agents list, open More create options, check that Agent, Standard is offered, choose nothing (nothing is created). Proves where creation starts and the exact option name. Does not prove that choosing it creates a Standard agent, what the creation flow asks next, or the harness of the page (the Agents list looks the same in every experience, so only the host is checked and the picture is saved for review).
2. `agent-overview.png` (section overview, kind after). The Overview page of the new Standard agent with the Details card, the Instructions card, and the model selector, on the tab strip Overview, Knowledge, Tools, Agents, Topics. Proves the agent exists and opens on the Standard tab strip. Does not prove that the name, description, or instructions were generated from a description (what the Standard create flow fills in was never read).
3. A Home picture (`copilot-studio-home.png`, `mc-harness-choice-home.png`) shows the shared Home, which looks the same in every harness. Its review message says so, and the lab step text does not claim that it shows the Standard create flow.

The lab step text of the create-agent feature now says: on the Home page, select the three dots at the bottom of the side bar, then Open classic experience (it opens in a new browser tab); on the Agents page, select More create options, then Agent, Standard. What the flow asks after that choice is unverified (read E10 before writing it).

- Allowed: click tabs and Settings links, the top-bar Test and Settings buttons, menu and dialog openers, the lower-left More options; hover; read role, exact accessible name, enabled or disabled state, headings and visible text; use a search box inside a dialog only as a filter.
- Never: Publish (top bar or inside any dialog), Save, Add, Add to agent, Create, Submit, Delete, Remove, Upload file, Sign in, Connect, Run, Evaluate; never flip a switch or radio; never type into any field except the Test panel textbox in E1 step 5 (needs approval).
- Leave each dialog or page with Close, Cancel, the X or Escape. If a discard prompt appears, something changed: stop, record it, choose Discard.
- Record for every control: role, exact name, state, order on the page, and the page address path.

E1. Test panel (any tab; slots: test-agent-panel.png, activity-map-plan.png, connected-agent-delegation.png; helps knowledge-answer-citation.png)
1. Read the panel header: heading 'Test your agent' and the buttons Chat mode, More, Expand test pane, Upload file, Send.
2. Click More. Read every menu item and its state (look for Track between topics, a new-session item, Variables, Show activity map). Press Escape.
3. Click Chat mode. Read what opens (menu, dialog or toggle) and every name. Escape without choosing.
4. Do not click Upload file.
5. With approval: type one harmless lab sample question into the textbox 'Ask a question or describe what you need, [agent name]' and click Send. When the answer ends, read the controls on or under the answer (activity map toggle, citation chips, feedback buttons) and what More now offers. Click nothing else.
