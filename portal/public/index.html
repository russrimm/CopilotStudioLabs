🧬 Build a Custom Lab

Answer one question at a time: industry, departments, level, harness, then the topics. Each answer changes the topics we recommend next. Every module is grounded against live Microsoft Learn documentation through the Microsoft Learn MCP server, so the steps and citations reflect the current product. Times are estimates to help you plan, never limits.

The level sets how deep the lab goes. Foundations a higher level depends on are added automatically.

A harness is the runtime behind a Copilot Studio agent. Each has its own authoring surface, so the lab follows one. Not sure? Compare the harnesses on Microsoft Learn (opens in a new tab).
